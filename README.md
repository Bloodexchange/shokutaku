# Shokutaku 食卓

Платформа, которая связывает заказчиков с кондитерами.

<img src="public/img/logo.svg" alt="Логотип" width="220">

## Что умеет сайт

- **Выбор на главной:** «Я заказчик» или «Я кондитер».
- **Заказчики:** регистрация по телефону и паролю (от 8 символов), вход, каталог кондитеров, поиск, фильтры (направления, опыт, город, сертификат), ИИ‑подбор через Gemini, заявки на заказ, отзывы со звёздами, личный кабинет.
- **Кондитеры:** анкета из 3 шагов: телефон, пароль, дата рождения (с 15 лет; до 18 лет обязательно имя и телефон родителя), город, стаж, где работали, направления, любимые блюда, сертификат (PDF/фото до 4 МБ), принятие условий с ключевым правилом о возврате средств. После одобрения кондитер виден в каталоге и принимает заявки в кабинете.
- **Контакты:** телефоны сторон открываются только после того, как кондитер принял заявку.
- **Администратор:** панель `/admin` (логин и пароль из переменных окружения) и закрытый Telegram‑бот: новые анкеты приходят с кнопками «Принять / Отклонить», сертификат приходит файлом. Команды бота: `/login логин пароль`, `/pending`, `/stats`, `/logout`.
- **Защита:** пароли хранятся только как bcrypt‑хеши, сессии в подписанных httpOnly‑куки, ограничение попыток входа, ключи только в переменных окружения.

## Как устроено

| Часть | Технология | Стоимость |
|---|---|---|
| Сайт и API | Vercel (статические страницы + Express как serverless‑функция) | бесплатно |
| База данных | Neon Postgres (через Vercel → Storage) | бесплатно |
| Telegram‑бот | вебхук на тот же сайт, сервер не нужен | бесплатно |
| ИИ | Google Gemini API | бесплатный лимит |

Таблицы в базе создаются автоматически при первом запросе.

## Деплой на Vercel (24/7, бесплатно)

1. На https://vercel.com/new импортируйте репозиторий `shokutaku` → **Deploy** (настройки по умолчанию).
2. В проекте: **Storage → Create Database → Neon (Postgres)** → подключить к проекту. Vercel сам добавит `DATABASE_URL`.
3. **Settings → Environment Variables** — добавьте:
   - `SESSION_SECRET` — любая длинная случайная строка (от 32 символов);
   - `ADMIN_LOGIN` — логин администратора;
   - `ADMIN_PASSWORD_HASH` — хеш пароля: `npm run hash-password -- "пароль"`;
   - `GEMINI_API_KEY` — ключ Gemini;
   - `TELEGRAM_BOT_TOKEN` — токен от @BotFather;
   - `TELEGRAM_WEBHOOK_SECRET` — любая случайная строка.
4. **Deployments → Redeploy**.
5. Откройте `https://<ваш-сайт>.vercel.app/admin`, войдите и нажмите **«Подключить бота»**.
6. В Telegram откройте своего бота и отправьте `/login логин пароль`. Бот удалит сообщение с паролем и запомнит только ваш чат.

## Локальный запуск

```bash
npm install
cp .env.example .env   # заполните значения
npm start              # http://localhost:3000
```

Нужен Node.js 20+ и Postgres (подойдёт та же база Neon).
